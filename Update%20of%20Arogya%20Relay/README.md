# Arogya Relay Update Prompts

This folder preserves four implementation-ready prompts for extending Arogya Relay.

## Problem statements

1. [Hybrid Offline/Online Clinical RAG](./Problem%20Statement%201/PROMPT.md)
2. [Precise Location, Hospitals and Health Camps](./Problem%20Statement%202/PROMPT.md)
3. [Indian Multilingual and Voice-Ready Experience](./Problem%20Statement%203/PROMPT.md)
4. [Doctor Schedules, Medicines and Care Reminders](./Problem%20Statement%204/PROMPT.md)

## Recommended order

Use the prompts in numerical order because the later features can reuse the safety, storage, clinical-data and language foundations created by the earlier prompts.

## Important boundary

Arogya Relay is currently a research/UI prototype. These prompts require synthetic data during development and formal review by qualified clinicians, pharmacists, privacy/legal specialists, security assessors and relevant medical-device regulators before any real-patient deployment.
